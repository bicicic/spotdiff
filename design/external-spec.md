# 外部仕様

## 確定した16項目

| 番号 | 選択 | 決定内容                                                            |
| ---- | ---- | ------------------------------------------------------------------- |
| 1    | B    | 絵・印刷物中心。軽い湾曲・凹凸は許容するが精度保証外                |
| 2    | B    | 撮影の注意点と補正プレビューを表示し、撮り直しは利用者が判断        |
| 3    | A    | 撮影と画像選択を別ボタンにする                                      |
| 4    | B    | JPEG・PNG・WebPを保証対象とし、その他はブラウザで読めれば受け付ける |
| 5    | A    | 1枚10MB以下、かつ2,400万画素以下                                    |
| 6    | A    | 仮の4隅を表示し、ドラッグで調整                                     |
| 7    | A    | 自動推定した共通比率で比較。実物の正確な縦横比は保証しない          |
| 8    | A    | 局所的な色変更を検出し、全体的な色かぶりは補正                      |
| 9    | B    | 通常の間違いを優先。微小な点・細線は保証対象外                      |
| 10   | B    | 補正済み1枚目・2枚目を切り替え、同じ差分マップを表示                |
| 11   | A    | 結果の拡大・移動、ヒートマップ切替、透明度調整                      |
| 12   | A    | 自動位置合わせ不調時は警告し、4隅補正で継続                         |
| 13   | A    | 永続保存しない。再読み込みで消去                                    |
| 14   | B    | 初回比較10秒以内を目標。画像読込とOpenCV初期化は除く                |
| 15   | B    | 箇所単位の検出率と誤検出候補数で評価                                |
| 16   | B    | 合成画像と標準条件の実際のスマホ写真で検証                          |

## 入力・操作

- 2枚に同じ対象の4隅が写るよう、同じ向き・均一な照明で撮影する。影、反射、ぼけを避ける注意を表示する。
- 端末標準カメラを呼び出す。対応しないPC等ではファイル選択となる。アプリ内カメラは設けない。
- 上限は10 × 1024 × 1024バイトと24,000,000画素。両方の条件を満たす画像を受け付ける。縦横32画素未満は比較に不適当として拒否する。
- 読込時に画像の向きを反映し、編集前に長辺1600px以下へ縮小する。90度回転も提供する。
- 4隅は左上・右上・右下・左下。番号の対応を2枚で揃える。範囲外、交差、逆順、極端に狭い領域では次へ進めない。
- ドラッグ時は拡大ルーペを表示し、選択した角を矢印キーで微調整できる。補正プレビューを確認して次へ進む。

## 結果・回復

- ヒートマップは黄色から赤で差の強さを示す。正解の確率ではない。
- 感度は0～100、初期値50。感度を上げると弱い差と撮影ノイズが増える。初期値へ戻せる。
- 差分候補数は連結した検出領域数であり、問題の正解数とは一致しない場合がある。
- 候補ゼロは「現在の感度で差分候補は見つかりませんでした」。解析エラーとは区別する。
- 戻る操作は画像と4隅を保持。画像差し替えはその画像の4隅と結果を無効化し、4隅変更は結果を無効化する。
- 処理中は段階を表示し、中断後は2枚目の4隅に戻る。初期化失敗や処理失敗でも画像を保持する。
- 全リセットは2枚の画像、結果、感度を初期状態へ戻す。

## 非対象と未確定事項

結果保存・共有、履歴、クラウド、PWA、立体物の視差補正は初版の対象外。最新のSafari・Chromeを対象とするが、実機確認の完了とは区別する。

精度の数値基準と性能検証端末は未確定。「検出率90%以上・誤検出平均2か所以内」は候補値であり、合意済みの合格条件ではない。
