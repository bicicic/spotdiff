# 画面設計

## 状態と遷移

`input → corners-first → corners-second → processing → result`

上部の3段階表示は「写真を選ぶ」「4隅を合わせる」「違いを見つける」。4隅工程では写真1/2・2/2を明示する。戻る操作で入力は保持する。

## 画像入力

スマホでは1枚目・2枚目カードを縦配置、PCでは横配置。各カードにプレビュー、ファイル名、撮影・画像選択の別ボタンを設ける。2枚揃うまで次へ進めない。デコード中は入力を無効化し、失敗時は入力画面に理由を表示する。

注意欄で均一な照明、4隅を含む撮影、向きを揃えることを案内する。画像が端末外へ送られないことと、再読込で消えることを表示する。

## 4隅編集

初期位置は画像端から5%内側。1左上・2右上・3右下・4左下のハンドルを表示する。画像の周囲に28 CSS pxの操作用余白を設け、画像外も含め48 CSS px以内で近いハンドルを選ぶ。操作領域全体でブラウザのスクロール・文字選択を抑止し、Pointer Captureとウィンドウのイベントで画像外までドラッグを追従する。座標は画像端で制限し、指が戻ればそのまま編集を継続する。操作を始めた指だけを追跡し、別の指による移動・終了は無視する。指を離した時、中断時、ウィンドウが非アクティブになった時に終了する。画面を離れたらイベントを解除する。ルーペは指と反対側に表示する。

角のボタンで対象を選択し、矢印キーで1画素相当、Shift＋矢印で10画素相当を動かせる。90度回転、4隅の初期化を提供する。四角形が無効な場合は理由を示して続行を無効化する。

補正プレビューは100msで更新する。1枚目の確定後は2枚目へ進み、2枚目の確定で比較を開始する。

## 比較中と結果

準備・遠近補正・位置合わせ・撮影差補正の段階を表示する。中断ボタンでWorkerを終了して4隅へ戻る。

結果では候補数または候補ゼロのメッセージ、位置合わせ警告、切替可能な2枚の補正画像を表示する。表示画像切替、差分表示のオン／オフ、100～400%の拡大、スクロール移動、透明度0～100%（初期65%）、感度0～100（初期50）を提供する。

感度変更は150ms待って再計算し、初期値へ戻せる。再計算中も表示画像・拡大率・透明度・スクロール位置を保持する。4隅調整へ戻る、画像選択へ戻る、全リセットを提供する。

## アクセシビリティ

ボタンに十分なタッチ領域を確保し、フォーカス表示と日本語の名前を付ける。候補数と進捗は`role=status`、エラーは`role=alert`。状態は色だけでなく番号・文言で示す。動きを減らす端末設定ではスピナーの回転を停止する。
